# What What

Orient the user without solving or relitigating the underlying task.

1. State the immediate ask in one plain sentence.
2. Give only the context needed to understand why that ask exists.
3. Separate requested changes from work that is already complete.
4. Name any decision or missing input the user must supply next.

Prefer one short paragraph or a few compact bullets. Preserve uncertainty, omit process trivia,
and do not invent intent that the thread does not establish. Use $write-humanly when available.
